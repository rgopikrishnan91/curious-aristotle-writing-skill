# Word Replacement Table

Replace on sight in academic prose.

| Replace | With |
|---|---|
| leverage (verb) | use |
| utilize | use |
| delve / delve into | examine, explore |
| robust | strong, reliable |
| comprehensive | thorough, complete |
| seamless / seamlessly | smooth, without friction |
| cutting-edge | latest, newest |
| pivotal | important, key |
| facilitate | enable, allow |
| underscores | shows, highlights |
| multifaceted | (name the facets) |
| holistic | complete, full |
| paradigm | model, approach |
| in order to | to |
| due to the fact that | because |
| serves as | is |
| actionable | practical, concrete |
| showcasing | showing |
| impactful | effective, significant |
| landscape (metaphor) | field, area |
| encompasses | includes, covers |
| novel (for own work) | new (let readers judge) |

## Concision Patterns

| Cut | Replace with |
|---|---|
| despite the fact that | although |
| in the event that | if |
| in a situation in which | when |
| as regards / concerning the matter of | about |
| it is crucial that | must |
| is able to / has the capacity for | can |
| it is possible that | may, might |

## Redundancies to Delete

- full and complete → complete
- each and every → every
- first and foremost → first
- basic and fundamental → fundamental
- past memories → memories
- future plans → plans
- end result → result
- pink in color → pink
- large in size → large
- basically, really, actually, virtually → (cut)
